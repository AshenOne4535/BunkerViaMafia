\# Bunkier: Ukryte Zagrożenie (System B-07)



Projekt zespołowy systemu informatycznego — wieloosobowa gra imprezowa łącząca mechaniki gier „Bunkier” oraz „Mafia” w architekturze wspólnego ekranu (Host/TV) oraz kontrolerów mobilnych (Smartfony).
